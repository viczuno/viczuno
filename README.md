## Featured projects

### [go-crypto-bot](https://github.com/viczuno/go-crypto-bot)

A market analytics platform with Go-based data ingestion and technical indicators, PostgreSQL-backed history, and a Next.js dashboard for market data and comparisons. The repository includes indicator and ingestion tests, database migrations, and scheduled workflows.

**Stack:** Go, TypeScript, Next.js, PostgreSQL, GitHub Actions

### [todo-list](https://github.com/viczuno/todo-list)

A Go task-management backend with separate REST and GraphQL services, GitHub OAuth, JWT refresh-token authentication, and role-based access control. Docker and Helm assets support deployment to Kubernetes with Istio.

**Stack:** Go, PostgreSQL, REST, GraphQL, Docker, Kubernetes, Helm, Istio
